How this tool works

The basics

Each card has a front and back. Start Review opens cards currently due. Review All includes all non-mastered cards in the current set/filter regardless of due date. Answer No / Stay to keep a card in its current box, or Yes / Move to advance it.

Leitner Review Cycles & Recall Mode

  • Box 1–4 intervals are fully configurable in Utilities.
  • Normal Box 4 promotion → card enters Box 1 in Recall Mode (Back shown first; recall Front).
  • Recall cards persist through Recall Box 1 → Recall Box 2 → Recall Box 3 → Recall Box 4.
  • Recall Box 4 promotion → Box 5 (Mastered).
